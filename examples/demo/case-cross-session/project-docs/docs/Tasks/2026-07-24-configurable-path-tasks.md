# 可配置 todo 文件路径 · 任务计划

first slice 控制在一次实现 session 可完成的范围内。

| ID | 任务 | 估算 | 完成标准 | Session |
|----|------|------|----------|---------|
| T1 | 定义 `--file` / `TODO_FILE` / 默认值的优先级契约 | 0.3h | 在 brief 与 design 中写清优先级。 | S1 |
| T2 | 解析 `--file` 参数（可位于子命令前后） | 0.5h | 传入 `--file` 后写入指定路径。 | S1 |
| T3 | 支持 `TODO_FILE` 环境变量回退 | 0.3h | 未传 `--file` 时读取环境变量。 | S1 |
| T4 | 保证默认 `.todo.txt` 行为不回归 | 0.3h | 两者缺省时输出与旧版一致。 | S2 |
| T5 | 补聚焦测试（含未知 id 错误路径） | 0.6h | 覆盖三条正常路径 + 一条错误路径。 | S2 |
| T6 | 跑 verify、写 handover、收口与 learn | 0.4h | 有测试证据、handover 与经验候选。 | S2 |

> 拆分说明：S1（session 1）完成 T1–T3 并交接；S2（session 2）恢复上下文后完成 T4–T6。
