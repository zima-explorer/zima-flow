# 新增可配置 todo 文件路径

## 为什么

已有 todo CLI 把任务固定写入当前目录的 `.todo.txt`。用户在多个目录间切换时会得到不同的列表，且无法把任务集中到一个已知位置。这是一个真实但很小的增量需求，适合用来演示跨 session 恢复上下文的闭环。

## 改动内容

- 新增 `--file <path>` 参数，显式指定 todo 文件位置。
- 新增 `TODO_FILE` 环境变量作为回退。
- 默认仍使用 `.todo.txt`，保证既有行为不回归。

## 不做什么

- 不做多个 todo 文件的合并或迁移。
- 不做云端同步。
- 不改动 `add` / `list` / `done` 的既有输出格式（避免破坏性变更）。
